# Hrithik Portfolio

This is a personal portfolio site built with React and styled using Tailwind CSS.

## 🌐 Live Site

👉 https://hrithikchandok.github.io/hrithik-portfolio

## 📦 How to Run Locally

```bash
git clone https://github.com/hrithikchandok/hrithik-portfolio.git
cd hrithik-portfolio
npm install
npm start
```

## 🚀 Deploy to GitHub Pages

```bash
npm install
npm run deploy
```

Make sure your GitHub repo is public and you've added this as the homepage in `package.json`.
